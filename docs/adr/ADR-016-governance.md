# ADR-016

Copied verbatim from the specification, chapter 0 §0.2 (`docs/spec/00-backbone.md` line 83, spec version 1.0.0-rc1). The specification is normative; when the two differ, the specification wins and this file is re-copied. The full rationale is in chapter 5.

## Decision

**Governance:** Developer Certificate of Origin (DCO), no CLA; no foundation initially; distinctive trademark registered early; distribution: macOS notarised DMG + Homebrew cask (never Mac App Store), Linux distro packages + Flathub, Android Google Play + F-Droid with reproducible builds.

## Why

From licensing research; GPL and Mac App Store are incompatible per FSF/VLC precedent.

## Alternatives rejected

CLA; LF hosting at start.
