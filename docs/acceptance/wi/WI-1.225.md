## Test 1: frame count, offsets and key frames equal ffprobe

`syn_av1_gop60_1080p.ivf` (chapter 14 §14.3.3 recipe 26) is generated by `tests/corpora/synthetic/generate.py`,
which is not in the tree yet (WI-0.553). The same test, `ivf: frame_count_actual, offsets and key frames equal
ffprobe` (`[container][ivf][ffprobe]`), was run on three files made with FFmpeg: AV1 (libaom, GOP 12), VP9
(libvpx-vp9, 30000/1001) and VP8 (libvpx, GOP 7). It reads `OVT_IVF_FFPROBE_FILE` and compares, per packet,
the sample offset, size and key-frame flag with `ffprobe -show_packets`:

```console
$ ffmpeg -f lavfi -i testsrc=size=320x240:rate=30 -frames:v 40 -c:v libaom-av1 -cpu-used 8 -g 12 av1.ivf
$ OVT_IVF_FFPROBE_FILE=av1.ivf ./ovt_tests_container "ivf: frame_count*"
All tests passed (123 assertions in 1 test case)
$ OVT_IVF_FFPROBE_FILE=vp9.ivf ./ovt_tests_container "ivf: frame_count*"
All tests passed (123 assertions in 1 test case)
$ OVT_IVF_FFPROBE_FILE=vp8.ivf ./ovt_tests_container "ivf: frame_count*"
All tests passed (93 assertions in 1 test case)
```

ffprobe's `pos` of an IVF packet is the offset of the 12-byte frame header (FFmpeg `ivfdec.c`: `pkt->pos -= 12`),
so the test compares `SampleTable.offset == pos + 12` (spec question #280, item 1).
