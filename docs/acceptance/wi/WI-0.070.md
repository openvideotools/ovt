## Deviations / assumptions

- `AppRun` is passed to `linuxdeploy` with `--custom-apprun`, so it sources `apprun-hooks/*.sh` itself (the Qt
  plugin's environment lives there). The CLI runs through the same AppRun as `AppImage --ovt-cli ...` or through a
  symlink named `ovt`; the spec does not say how the CLI is reached inside the image.
- A user-set `OVT_PLUGIN_PATH` is kept and the bundled directory is appended (spec §13.6.2 only says AppRun sets it).
- The desktop file is generated by the script until WI-0.071 adds `app/resources/org.openvideotools.Studio.desktop`;
  the script prefers that file once it exists.
- `usr/lib64` (Fedora-style `GNUInstallDirs`) is folded into `usr/lib`; the Ubuntu 22.04 build host uses `usr/lib`.
- Not done: signing and publishing (WI-0.036); the codec-pack tarball (not in this WI's Produces).
